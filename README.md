# Юридические документы игры YouLife

Публичный сайт с политикой конфиденциальности, лицензионным соглашением и порядком удаления
аккаунта игры «YouLife».

Здесь нет исходного кода игры — только документы, которые по закону и по требованиям
магазинов должны быть общедоступны, и генератор, который превращает их в страницы.

## Документы

| Файл | Что это |
|---|---|
| `PRIVACY_POLICY.md` | Политика в отношении обработки персональных данных (152-ФЗ) |
| `TERMS_OF_USE.md` | Лицензионное соглашение и публичная оферта |
| `DELETE_ACCOUNT.md` | Порядок удаления аккаунта и данных (ссылка для RuStore и Google Play) |
| `THIRD_PARTY_NOTICES.md` | Компоненты третьих лиц и их лицензии — неотъемлемая часть соглашения (п. 12.2) |
| `LEGAL_REQUISITES.md` | Реквизиты правообладателя — на них ссылается соглашение (п. 12.3) |
| `docs/ANALYTICS_EVENTS.md` | Закрытый перечень событий счётчиков — на него ссылается раздел 5 Политики |

Каждый документ, на который ссылается другой, должен лежать здесь: ссылки внутри текстов
превращаются генератором в ссылки на страницы сайта, и «висячая» ссылка на неопубликованный
файл сразу видна как обычный текст. Источник — папка `legal/` репозитория игры; этот
репозиторий — её точная копия, второй редакции текста не существует.

## Как это опубликовано

`site/build.py` собирает HTML из Markdown-файлов в корне, `.github/workflows/pages.yml`
публикует результат на GitHub Pages.

Включить: **Settings → Pages → Source → GitHub Actions**, затем
**Actions → Legal site → Run workflow**.

Адрес после включения: <https://anton-shcherbakov01.github.io/youlife-legal/>

| Страница | Для чего |
|---|---|
| `privacy.html` | ссылка на политику в карточках RuStore и Google Play |
| `terms.html` | лицензионное соглашение |
| `delete-account.html` | ссылка «удаление аккаунта» в Google Play (раздел «Безопасность данных») |

Сервер игры переадресует `https://api.ulike-bot.ru/privacy`, `/terms`, `/delete-account`
на эти страницы.

## Посмотреть локально

```bash
pip install markdown
python3 site/build.py --serve      # http://localhost:8000
```

## Как обновить текст

Правите Markdown в папке `legal/` репозитория игры и копируете её содержимое сюда — при пуше
в `main` сайт пересобирается сам.
