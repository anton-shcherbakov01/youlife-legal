# События счётчиков YouLife

Закрытый перечень событий, на который ссылается раздел 5 Политики (`PRIVACY_POLICY.md`).
Сервер принимает только события из этого списка; любые другие отбрасывает.

Игра отправляет не сами события, а **число** их наступлений за день вместе с версией игры
и каналом распространения. Идентификаторов пользователя, аккаунта и устройства в счётчиках
нет. Отправка выключается в «Устав» → «Аккаунт, магазин и помощь».

| Событие | Когда учитывается |
|---|---|
| `first_open` | первый запуск после установки (один раз на установку) |
| `day_active` | игра запускалась в этот день (не чаще одного раза в сутки на устройстве) |
| `app_started` | запуск игры |
| `session_started` | начало игровой сессии |
| `tutorial_step` | пройден шаг обучения |
| `store_opened` | открыт экран «Магазин» |
| `purchase_click` | нажата кнопка покупки |
| `purchase_flow_started` | открыто окно оплаты магазина приложений |
| `purchase_store_success` | магазин сообщил об оплате |
| `purchase_granted` | покупка подтверждена сервером и открыта |
| `purchase_cancelled` | покупка отменена |
| `purchase_error` | ошибка покупки |
| `restore_started` | нажато «Восстановить покупки» |
| `restore_finished` | восстановление завершено |
| `support_sent` | отправлено обращение в поддержку |
| `save_exported` | партия выгружена в файл |
| `save_imported` | партия загружена из файла |
| `save_recovered` | партия восстановлена из запасной копии |
| `cloud_backup` | партия сохранена в облако |
| `rating_prompt_shown` | показано предложение оценить игру |

Не все события из перечня отправляет текущая версия игры: перечень задаёт верхнюю границу
того, что может быть принято.
